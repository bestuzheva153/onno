# Сервис подписок

Приложение на onno Framework для учета подписок клиентов на тарифы.

Клиент пополняет лицевой счет платежом. Затем для него оформляется подписка:
в документе выбираются один или несколько тарифов, количество периодов и дата начала.
При сохранении подписки пересчитываются цена, сумма строки, итог и дата окончания.
При проведении подписки деньги списываются с лицевого счета, а выручка попадает в регистр по тарифам.

## Модель

- `Client` - клиент, e-mail, телефон, статус и дата регистрации.
- `Tariff` - цена периода, длительность периода в днях и признак доступности.
- `Payment` - документ пополнения лицевого счета.
- `Subscription` - документ подписки с табличной частью `SubscriptionLine`.
- `PersonalAccount` - регистр остатков по лицевым счетам клиентов.
- `RevenueByTariff` - регистр оборотов выручки по тарифам и клиентам.

Статусы подписок обновляет регламентное задание `refreshSubscriptionStatuses`.
Оно переводит проведенные подписки в `ACTIVE` или `EXPIRED` по датам. Отмененная подписка движений не создает.
Подписку можно отменить из списка или формы с указанием причины.

## Запуск

Нужны JDK 21 и Maven.

```bash
mvn spring-boot:run
```

Приложение использует H2-файл:

```text
./data/subscriptions
```

Логин для локальной проверки:

```text
admin / admin
```

## Проверка

```bash
mvn test
```

Тесты покрывают пересчет подписки, проверки баланса, правила платежа и движения по регистрам.
